# 🎙️ Voice-Enabled RAG Assistant

A voice-first knowledge retrieval assistant powered by **Vapi AI**, **Groq**, **LangChain**, and **ChromaDB**.

## 🚀 Features
- **Document Ingestion:** PDF, TXT, DOCX files indexing into ChromaDB.
- **RAG Engine:** Semantic similarity search with LangChain & Groq LLMs.
- **Voice Agent:** Real-time WebRTC voice interaction powered by Vapi.
- **FastAPI Webhooks:** Dynamic tool calling to fetch knowledge base context.
